How It Works

This HRM system allows you to create and manage employees, departments, and skills. You can assign employees to departments, track their skills, and view a summary of the workforce in a dynamic dashboard. Role-based access ensures secure usage: Admins and Developers have full access, while Visitors have limited view-only permissions.

1. Dashboard Overview

The dashboard provides a quick overview of total Employees, Departments, and Skills. It serves as the starting point for navigating to any HRM management section.

2. Adding a New Department

Go to Departments → Add Department → Enter the department name → Save. Departments organize your employees, making filtering and management easier.

3. Adding a New Skill

Go to Skills → Add Skill → Enter the skill name → Save. Tracking employee skills helps in assigning projects and training.

4. Adding a New Employee

Go to Employees → Add Employee → Fill in details → Select Department → Add Skills → Save. Centralizes employee data for easy management.

5. Viewing Employee Details

View employee info, assigned department, and skills. Helps in performance tracking and project assignments.

6. Filtering Employees by Department

Use the department dropdown to filter employees dynamically. Makes it easier to manage departmental staff.

8. Security & Access Control

Admins/Developers have full access. Visitors have view-only access. Protects sensitive HR data and reduces errors.
